STYLESHEET SETUP INSTRUCTIONS
============================

This document provides step-by-step instructions for adding a stylesheet to your .NET project.

## Method 1: Using CSS File in ASP.NET Core Project

1. Create a new CSS file in your project:
   - Location: wwwroot/css/styles.css (for web projects)
   
2. Add basic CSS content:
   ```css
   body {
       font-family: Arial, sans-serif;
       margin: 0;
       padding: 0;
       background-color: #f5f5f5;
   }
   
   h1 {
       color: #333;
       text-align: center;
   }
   ```

3. Link the stylesheet in your HTML file (usually in Layout.cshtml or _Layout.cshtml):
   ```html
   <link rel="stylesheet" href="~/css/styles.css" />
   ```

## Method 2: Using Bootstrap for Quick Styling

1. Add Bootstrap via CDN in your HTML head section:
   ```html
   <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
   ```

2. Use Bootstrap classes in your HTML elements:
   ```html
   <div class="container">
       <h1 class="text-center mt-5">Hello Dotnet Upskilling World</h1>
   </div>
   ```

## Method 3: Using Tailwind CSS

1. Install Tailwind CSS via npm:
   ```
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```

2. Add your template paths to tailwind.config.js:
   ```javascript
   content: ["./Pages/**/*.cshtml"]
   ```

3. Include Tailwind in your CSS file:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```

## Best Practices

- Keep stylesheets modular and organized by feature
- Use meaningful class names (BEM naming convention recommended)
- Minimize CSS files for production deployment
- Use CSS variables for consistent theming
- Test stylesheets across different browsers
